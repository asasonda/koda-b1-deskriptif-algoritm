# Algoritma Luar dan Keliling Lingkarang

```
1. Mulai
2. Masukkan jari-jari lingkaran
3. lalu hitung keliling lingkaran dengan mengalikan jari-jari tersebut dengan 2 x 3.14
4. Tampilkan hasil keliling lingkaran
5. untuk menghitung luas lingkarannya mengalikan 3.14 dengan hasil jari-jari kuadrat.
6. Tampilkan hasil luas lingkaran
7. Selesai
```
